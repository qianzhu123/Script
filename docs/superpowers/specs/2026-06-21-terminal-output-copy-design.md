# 终端运行结果复制功能设计

## 目标

为脚本终端输出提供一个符号化复制按钮，使用户能够一键复制当前活动运行实例的完整输出。

## 交互设计

- 复制按钮放在终端输出框右上角，与被复制内容保持明确关联。
- 按钮默认显示 `⧉`，通过 `title` 和 `aria-label` 说明用途。
- 没有活动运行实例或活动实例没有输出时，按钮禁用，默认提示文字不会被复制。
- 复制成功后短暂显示 `✓`，复制失败后短暂显示 `!`，随后恢复 `⧉`。
- 切换运行实例时，按钮复制新活动实例的 `session.output`。

## 实现边界

- 在 `public/index.html` 中为终端增加定位容器和复制按钮。
- 在 `public/style.css` 中将按钮定位到输出框右上角，并保证不遮挡输出文字。
- 在 `public/app.js` 中集中实现复制和按钮状态同步。
- 优先使用 Clipboard API；不可用或失败时使用浏览器兼容回退方法。
- 不修改服务端、脚本执行协议或运行实例数据结构。

## 测试与验证

- 自动化测试覆盖：复制活动实例输出、空输出禁用、成功/失败反馈及 Clipboard API 回退。
- 运行项目现有 `npm test` 和 `npm run check`。
- 在浏览器中验证按钮位置、运行实例切换、实际剪贴板内容和窄屏布局。
